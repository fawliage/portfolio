Sample Bug Report

Comprehensive bug documentation with root-cause isolation.

D001
Low Severity Open / Under Review
Bug Description
Student account created successfully; but it redirect to login page instead of dashboard. It then resulted to: Students must be able to sign up their accounts in the system using their institutional account via in-system login fields
Root Cause Analysis
The root cause for this is the route trigerred after inputting the signup credentials and clicking the sign-up button, it redirected the user back to the login ("/login") rather than the dashboard route ("/dashboard"). This was intended to prompt users to reauthenticate themselves before logging in to test their newly created credentials. Although this causes an additional workload for the users.
The Fix
The programmer redirected the route upon signup from going login to dashboard. This simplifies the navigation logic and minimize user burden upon system navigation. By also altering the authentication rules (on signup), it immediately saves user session upon sign up, rather than prompting users to signup then manual loggin in. This then ensures that the user experience is enhanced.
