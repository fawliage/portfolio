# Quality Assurance Artifacts Directory
Add your actual QA artifact documents or PDFs here. The QA section buttons link directly to these files:

- `sample-test-cases.pdf`: Linked by the **"View Full Test Cases Document"** button. Replace with your actual exported test case suite or test matrix PDF.
- `sample-bug-report.pdf`: Linked by the **"View Full Bug Report Document"** button. Replace with your actual sanitized bug/defect report PDF.

You can also change the `href` attribute in `index.html` to point to any other file name or Google Drive/Sheets share link if preferred.
